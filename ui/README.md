# WatchSense UI

Nuxt 4 application: Vue UI (`app/`) and Nitro API server (`server/`).

See the main [README](../README.md) ([italiano](../README.it.md)) and the [configuration guide](../docs/CONFIGURATION.md).

```bash
npm install
npm run dev      # http://localhost:3333
npm run build    # then: node .output/server/index.mjs
```
